Все последние правки включены. Картинки и шрифты находятся в assets/.
Установка программ, сервер и сборка не нужны.

БЕСПЛАТНО ЧЕРЕЗ CLOUDFLARE PAGES
1. Создай аккаунт: https://dash.cloudflare.com/
2. Открой Workers & Pages.
3. Выбери Create application → Get started → Drag and drop your files (проект Pages).
4. Введи имя сайта и загрузи Masha_site.zip целиком.
5. Нажми Deploy site (или Save and Deploy).
6. Отправь Маше полученную ссылку вида название.pages.dev.

Используй тариф Free. Для этого сайта покупать домен и вводить карту не нужно.
Посетителям сайта аккаунт ChatGPT не понадобится.

ZIP можно загрузить напрямую. Если загружаешь распакованную папку, в ней
должны находиться index.html, app.js, style.css и папка assets/.

Для обновления файлов используй Create a new deployment.
Текст меняется в index.html, реплики теста — в app.js, оформление — в style.css.

Официальные инструкции:
https://developers.cloudflare.com/pages/get-started/direct-upload/
