# Маше. С любовью, Максим

Личный сайт-поздравление с 11 октября.

Статический HTML/CSS/JavaScript: сборка и сервер не требуются. Картинки и шрифты — в `assets/`.

- `index.html` — страницы и письмо.
- `app.js` — тест «Эффект манго», сюрпризы и анимация.
- `style.css` — оформление и адаптация под телефон.
- `README_RU.txt` — инструкция по бесплатному размещению.

Для размещения загрузи содержимое этой папки в Cloudflare Pages через Direct Upload.
